## 命名与时机规范

1. 插件 id 用小写字母 + 数字 + 连字符，必须等于目录名。
2. **description 第一句必须写「什么时刻调」**，其余再讲功能。
3. `exampleQueries` ≤ 3 条，写成用户会说的话，不是功能名。
4. 本文件的第一节固定是「此刻该调哪个 skill」表。
5. 阶段词只用 开工 / 推进 / 验收 / 收尾。
6. 每个 skill 的 frontmatter `description` 自带触发词，agent 能自己选中。
